# 🏠 Kotha Bhada

A Flutter-based room rental mobile application that connects landlords and tenants, enabling users to list, browse, and search for rental rooms with real-time data powered by Firebase.

## ✨ Features

- User authentication with Firebase
- Browse and search room listings
- Add, edit, and delete room listings
- Upload room images
- View detailed room information
- Real-time database updates

## 🛠️ Tech Stack

- **Frontend:** Flutter, Dart
- **Backend:** Firebase
- **Database:** Cloud Firestore
- **Authentication:** Firebase Authentication
- **Storage:** Firebase Storage

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/kotha-bhada.git
cd kotha-bhada
flutter pub get
flutter run
```
